# 中文期刊补充能力的稳定化验收

状态：2026-09-28，**范围明确的中文线索服务通过稳定化验收**，可作为显式启用的功能用于 `search`、`pull-now` 和 `weekly-run`。P0/P1 已完成隔离端到端与来源故障验收；P2 已完成逐期核算口径、十五刊入口处置和来源使用边界。九刊可自动采集目录，六刊保留逐站说明的人工状态。这个稳定判定不包含八周实验结论、研究兴趣论文召回率或逐篇已确认新论文；本次是 `main` 分支代码与文档更新，不宣布新版本标签或 GitHub Release。

## 两种不同的承诺

1. **范围明确的中文线索服务**：用户显式启用后，`search` 展示有来源的中文题录候选，`pull-now` 只展示与滚动窗口相交且有明确月份的线索，`weekly-run` 对新观察期次建基线、去重并报告失败。它不声称候选都在本周发表、都符合研究兴趣或覆盖了所有中国哲学论文。这个有限承诺可以先于到达时间实验完成而验收。
2. **已确认新论文服务**：中文作品要进入与 PhilPapers 匹配论文相同的主栏，还须逐篇证明作品类型、发表或新近来源到达、用户已确认兴趣分类、发表时署名中国机构（在此范围适用时）及跨来源作品同一性。仅凭刊名、关键词、作者姓名或数据库查到的日期均不足以满足这些条件。此承诺尚未完成，不能随线索服务一起宣布稳定。

目前三种模式已接通有界知网空间候选和本地已复核期次；公开示例默认关闭中文来源。十五种登记期刊中八种可独立采集文字目录，另有一种可有界采集刊方目录 PDF；其余六种已有逐站人工处置与再次接入条件。自动采集目录默认是待核证据，尚不能自动进入三种模式；维普自动接口未接入，万方为显式开启的补充来源。这些是范围边界，不以八周实验结果替代。

## 稳定判定

### 2026-09-28 P2 阶段记录

- `journal-watch audit` 现分别给出完整刊方目录、人工确认的研究论文、人工确认的兴趣相关论文三个分母。只要某期仍有未核或存疑条目，相应较窄分母为 `null`；分来源的研究论文可见性分母还要求逐篇完整查询及已保存查询范围。失败、截断、未查和资料不足均列为未解，不进入完整未命中。隔离库九期 132 条目录的刊方分母成立，研究和兴趣分母目前均未知：这些条目没有完成逐篇人工分类，不能推得召回率。
- 同日另建隔离副本，显式开启一次万方 Query 双来源核对：同篇在知网空间的标题加年份查询完整命中，在万方标题查询完整未命中，两者各取得 1/1 页。修正刊方中文姓名内空格被误拆成两位作者的问题后，知网结果复查为命中。合计只抽查《孔子研究》两篇知网命中，其中一篇与万方比较；这一结果不能推断万方全库缺收、固定到达延迟或来源总体召回率，普通运行的万方开关仍保持关闭。
- [六刊入口逐站审查](publisher-article-observation.md#2026-09-28-六站入口复核与自动采集决定)已记录官方线索、2026-09-28 运行环境结果与再次接入条件。《中国社会科学》官网既有第 8 期公众号目录提示，也有按期逐篇栏目，但本机直连及来源使用条件未通过；《伦理学研究》官网过刊页可见文字线索，本机返回 502；《宗教学研究》目录是图片；其余三刊当前登记入口没有可验证的当期刊方逐篇目录。六刊继续人工核对，不被解释为没有新刊。[第三方与来源使用说明](../THIRD_PARTY_NOTICES.md#中文期刊发布渠道及补充检索)补齐访问、请求频率、保存字段和公开展示边界；万方默认关闭。

- [《孔子研究》主办方栏目](https://www.chinakongzi.org/category/kongziyanjiu_qikan/)与[第 4 期目录页](https://www.chinakongzi.org/content/6147_589032.html)均可从同一登记主机获取。新采集器限制为索引页和一条期次页，验证期号、15 条作者题名及目录后段对应的逐篇标题；页面标示的 2026-08-13 仅作为待核公告日，不补造期次月份。2026 年第 3 期的同站目录也通过解析结构试读。
- 2026-09-28 新建 Git 忽略隔离库，九站各一整期均完成有界扫描，共 132 条目录记录，默认没有逐篇数据库查询。仅对新增刊物抽一篇作知网公共检索面的完整标题核对，结果为命中；另外 14 条《孔子研究》目录记录以及其他站点在**本轮**未核对，万方未开启。这个单次结果不构成数据库收录时差或总体覆盖率。
- 同篇到达汇总现在只使用保存了查询范围且标明 `complete=1` 的 `miss` 作为“最后一次完整未命中”。旧库中没有范围的 `miss`、截断查询及失败不形成到达区间；逐期审计单列完整未命中数。已保存的原始观察行不被改写。

### 2026-09-27 P2 阶段记录

- `journal-watch audit` 逐刊逐期列出成功采集的刊方目录记录数，并只在页数、条数及当前题名指纹与完整扫描一致时给出参考分母；旧库或截断记录不补造分母。逐篇可查看知网、可选万方核对的最后状态、检索范围、实际页数与完整性。`classify` 要求人工核对登记原站 URL，分别标注作品类型与本地兴趣相关性；未核条目不自动算作研究论文。
- 第八个入口为[中山大学《现代哲学》官方目录](https://mphilosophy.sysu.edu.cn/cat/124)的 PDF。2026 年第 2 期的目录 PDF 明示“三月号”，[官网公告页](https://mphilosophy.sysu.edu.cn/article/25746)日期为 2026-06-29；系统分别保存两条待核证据，不把公告日作为期次月份或逐篇首发日期。对 PDF 设置 HTTPS 登记主机、大小、页数、内容类型、文件头与期次条数核对；不保存原 PDF。
- 隔离库对八刊各一整期的实采得到 117 条目录记录。按每站一篇有界检查知网公共查询面，八次完整题名查询均命中；其余 109 条未在此轮逐篇核对，万方未开启，也未完成作品类型和兴趣的人工分类。这不能得出数据库全库召回率、固定到达时间或中文哲学论文总体覆盖率。
- 采集只保存有限题录字段与官方证据 URL；[第三方与来源使用说明](../THIRD_PARTY_NOTICES.md)记录 `pypdf` 许可、刊方 PDF 的使用边界、知网公共检索与万方授权 Query 的区别。万方到达对照仍须显式开启。

### 2026-09-27 P0/P1 验收记录

- 三种模式以隔离临时配置、公开测试词和模拟网络响应完成端到端回归：`search`、`pull-now`、`weekly-run` 保留“已匹配论文／中文题录候选／刊方期次线索”界线；近月只取明确月份与窗口相交的候选；周报验证基线、次周新期和重复运行去重；关闭中文数据库来源时三种模式均不调用对应加载器。测试不读取私人 watchlist、密钥、历史状态或报告。
- `journal-watch pending` 显示自动采集的待核期次；`review` 只能对已观察的同一官方 URL 在人工核实后提升状态。原始所见时间与首次核实时间分开保留，重扫不降级；同一期多个官方链接在用户报告中合为一条，周报按最早核实周报告。即使网页自动读到公告日，也先留待人工复核；缺月和缺日不推断。自动目录记录仍不是逐篇已确认论文。
- 对重定向、非 HTML、HTTP 429、页面过大、分页超界及单站失败做了回归测试；截断不会保存为完整目录，一站限流不阻断其余站。独立检索在本地官方证据库损坏时标示来源失败并继续；不能把失败解释为零新文。
- 有界真实来源试跑只访问登记主机：新建隔离库第一次扫描[《哲学研究》编辑部门户](https://zxyj.cbpt.cnki.net/portal/journal/portal/client/paper_list/type_benqi)的 2026 年第 8 期，读到 12 条、3 页，状态保持 `pending`；另一新建隔离库扫描[《周易研究》主办单位目录](https://zhouyi.sdu.edu.cn/info/1033/2558.htm)的 2026 年第 4 期，读到 11 条、2 页，初始为 `pending`。人工打开后确认该页写明 2026-08-21 **公告日**，再在隔离库执行 `review` 并重扫，状态仍为 `reviewed`。没有把该公告日写成期刊刊出日或九月新文。
- 全套 391 项测试、Ruff、skill 校验和只读发布检查通过。验收脚本与公开夹具随仓库保存，真实试跑数据库仅置于 Git 忽略的 `var/`。本记录是有限工作流的验收证据，不是七站全部持续可访问、十五刊全部自动覆盖或中文论文全部召回的证明。

上述 P0/P1 有可复现证据；P2 已明确支持刊物、人工入口及可成立的逐期分母。因而从本次更新起，将**范围明确的中文线索服务**列入稳定功能：显式启用后提供有界候选和已复核期次，来源不可用时报告受影响范围。此判定不要求先取得商业数据库的全库权限，也不把局部结果写成全体中文哲学论文的覆盖率。来源网页或订阅条件改变时，受影响来源须按故障状态降级并重新验收。

约八周的同篇复查只检验来源可见性、站点结构与到达区间。它既不是线索服务稳定化的唯一门槛，也不能代替端到端验收、来源使用边界或逐篇兴趣与机构核验。若以后要升级为“已确认新中文论文”，须另设逐篇证据、分类映射、作品去重与真实新出判定的验收，再决定其发布状态。
