# v0.4.0 发布候选检查

状态：2026-10-08，本地独立分支候选；尚未创建 `v0.4.0` 标签或 GitHub Release。

## 发布承诺

本候选把[已验收的有界中文期刊线索](chinese-journal-stabilization.md)纳入应用版本：用户显式启用后，`search` 展示有来源的题录候选，`pull-now` 与 `weekly-run` 只在出版月份有证据且与各自窗口相交时列出中文线索。三种模式共用已复核的刊方日期证据；周报对已列期次和记录去重，并分别说明来源失败、缺月、窗外和先前已列的数量。已匹配 PhilPapers 论文继续使用原有作品类型、分类交集和新近性门槛。

九种登记期刊可有界采集官方目录；其余六种按站点保留人工复核状态。自动目录也须核实证据才能进入用户报告。中文题录候选不自动成为逐篇“已确认新发表论文”。本候选不承诺十五刊全自动覆盖、中文哲学论文全库召回率、固定数据库到达时限或研究兴趣论文召回率。约八周的同篇观察用于来源评估，不是上述有限功能的发布门槛。

## 代码与包

- 应用版本：`0.4.0`，在 `pyproject.toml`、包内 `__version__` 和 `uv.lock` 中一致；内部证据管线版本仍为 `0.6.0`。
- 发布材料：源码包与 wheel 由当前分支构建；源码包应包含 Skill 入口、中英文 README、CHANGELOG、参考政策、候选准备脚本和测试；两个包均不得包含私人 watchlist、状态库、报告、凭据或 `var/` 内容。
- 只读发布检查排除 Git 链接工作树的 `.git` 元数据指针文件，并继续核对 Git 实际跟踪集合；相应回归测试已加入。
- 公开 `v0.3.0` 的状态库 schema 为 4，候选版为 6。合成旧库的 schema 4、5 升级测试验证先生成完整性通过的备份，原有检查点及通知记录保留；正式私人库仍须在独立副本上核查。升级步骤见[中文安装指南](installation.md#v040-候选的升级核查)和[英文安装指南](installation.en.md#upgrade-checks-for-the-v040-candidate)。
- 本候选只在独立分支处理公开文件；主检出目录中的私人配置、历史状态和报告不参与构建或验收。
