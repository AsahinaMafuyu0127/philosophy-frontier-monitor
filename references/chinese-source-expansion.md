# 中文论文来源扩展：范围与接入门槛

状态：重点期刊官方渠道目录和本地期次证据库已接入；八站文字目录与《现代哲学》刊方 PDF 目录已完成有界逐站实采，其余六站保留人工核对
最后核查：2026-09-28

## 1. 目标集合

目标是尽量发现与用户已确认哲学兴趣相关的世界及中国论文。候选来源按并集组合：

```text
候选 = PhilPapers 分类来源记录 ∪ 经核验的中文来源记录
```

**不得按作者机构过滤 PhilPapers 来源。** 它承担全球发现，也可能覆盖部分中国论文。中文来源
补充其中未被 PhilPapers 收录的论文；新增来源的使命是扩大召回范围，而不是把现有全球范围缩成
“中国机构作者”。跨来源重复记录只形成一个作品，并保留每个来源的出处。

中文补充通道优先寻找发表时至少一名作者署名中国机构的哲学论文。机构证据应来自该论文的作者
署名或可核验的结构化机构字段；姓名、文字语言、期刊所在地和作者当前任职机构不能代替发表时
署名。机构字段缺失时记录为未知，不能猜测国籍。PhilPapers 已发现的作品不受这一条件限制。

“尽量涵盖”是可测量的覆盖目标，不是“已穷尽全部哲学论文”的保证。每个运行结果应分别披露
来源成功、失败、可用时间范围、候选数和未能核验的记录；平台收录量不能直接当作本项目覆盖率。

## 2. 来源调查

下表区分供人检索的网页与可供长期自动运行的正式接口。没有核实到接口，不等于断言接口不存在。

| 来源 | 已核实的能力 | 尚待取得或核实的运行条件 |
| --- | --- | --- |
| [PhilPapers](https://philpapers.org/help/faq.html) | 现有分类 RSS 与兴趣分类成员关系；继续承担全球候选发现。 | 分类 feed 不代表全球完整书目，来源到达时间不等于发表日期。 |
| [中国知网](https://www.cnki.net/) | 中文期刊检索；部分签约期刊在纸刊前[网络首发](https://yxsg.cbpt.cnki.net/portal/journal/portal/client/news/cb7337c7f9ef1931059f7dcb5b384ada)。 | 核实正式检索或元数据接口、授权范围、分页、增量字段、日期语义、自动访问频率和可保留字段。不能将网络首发推广为所有期刊的更新承诺。 |
| [万方 AI HUB](https://ai.wfdata.com/skills/api) | 用户账户显示“万方文献检索”已订阅、试用中；其服务说明给出 `POST https://api.wfdata.com/openwanfang/getQuery`、`X-Ca-AppKey`、`OpenPeriodicalChi`、分页参数及逐篇书目字段。[万方开放文献检索字段说明](https://github.com/wanfangdata/wfdata-open-skills/blob/master/skills/wfdata-search/references/api-catalog.md)可辅助理解字段。 | 本机有限真实试调已确认鉴权与题录响应；实际结构与页面示例有别。账号额度、长期稳定性及全库覆盖仍未知；`PublishDate`、文摘上网日期与首次发表不能混同。不同产品的签名方案不能直接套用到该订阅接口。 |
| [维普](https://www.cqvip.com/journal) | 中文期刊检索，并按[中图分类法](https://csi1.cqvip.com/productor/pro_zk.shtml)标引文献。 | 核实正式可自动访问的接口、授权与字段契约；网页检索表单不是可直接依赖的 API。 |
| [国家哲学社会科学文献中心](https://www.ncpssd.cn/journal/index) | 公益性中文社科期刊入口，提供哲学分类、文章与期刊检索；据[中国社会科学网 2026 年介绍](https://www.cssn.cn/skgz/bwyc/202605/t20260514_5989275.shtml)，提供同步更新与优先发布服务。 | 核实正式机器接口或获准合作方式、卷期／在线日期语义和分类字段。平台总体同步服务不能证明每篇文章均按周完整到达。 |
| [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | 公开元数据可按出版日期、索引日期检索；无需上述三家数据库的全库许可。 | 仅覆盖向 Crossref 注册的作品，中文哲学期刊的实际召回率尚须抽样测量；不能以 DOI 来源代替无 DOI 论文。 |
| [DOAJ OAI-PMH](https://doaj.org/docs/oai-pmh/) | 提供开放获取期刊文章的 OAI 元数据和主题集合，可作为以后免个别商业库全库许可的补充。 | 只覆盖 DOAJ 收录的开放获取期刊；官方说明无登录公开 feed 可比当前记录滞后至多 30 天，因此不能独自承担近月及时监测；具体中文哲学期刊覆盖待实测。 |

这些公共书目与开放获取通道可增加召回，却没有一个可据现有证据代替知网、万方、维普
全部中文哲学期刊。对已列入监控库的重点期刊，检索顺序改为：期刊编辑部或主办单位的官网、
正式期刊门户和可核实身份的官方公众号，优先发现期次及其日期证据；知网空间可补充发现和逐篇书目核对，万方仅在用户显式启用时作为补充来源。编辑部发布、但由知网承载的门户属于期刊发布渠道；它与
知网题录库不构成两个独立来源。原站页面可读不等于获准批量抓取，公众号发文日不自动
等于期刊刊出日或论文首次发表日。

### 2.1 现有个人订阅的万方独立发现

万方官方 [Query 字段目录](https://github.com/wanfangdata/wfdata-open-skills/blob/master/skills/wfdata-search/references/api-catalog.md)
列出 `OpenPeriodicalChi`、检索表达式、排序、分页、`PublishDate` 与逐篇题录字段。2026-09-27
用本机既有个人订阅做少量通用词试调：限定年份的检索返回 HTTP 200、题录总数及期刊字段；
按 `PublishDate` 降序也返回结果。试调同时发现“第 4 期”配 `2026-01-01`，以及晚于检索日的
标示日期。这些事实支持**有界候选发现**，不支持把 `PublishDate` 逐字认定为首次发表日。

可选 `sources.wanfang.discover: true` 复用私人中文术语，默认每次最多两个词、每词一年一页；
最高可配置三个词、两页。三种模式都将万方独立候选单列，不以知网是否命中为前提；独立检索
展示有限候选，即时拉取只列来源出版月份与窗口相交且未被识别为年份占位日期的候选，周报
第一次建立窗口内万方记录 ID 基线，以后只列此前未列入窗口且月份与窗口相交的记录。窗口相交是月精度
候选筛选，不是发表日核验。任何失败、截断和无月均计入覆盖；试用额度可能消耗，默认不自动
开启。已订阅 Query 返回的可见题录范围不等于获得批量导出全库的权限。

### 2.2 知网空间的探索性候选通道

[Biogod2020/cnki-search](https://github.com/Biogod2020/cnki-search/tree/0435306d7ca6df823a43cea44b3645cfa3ede05f)
是 MIT 许可的第三方 MCP；它读取 `search.cnki.com.cn` 的公开网页检索结果，提供 `search` 与
`get_record` 两个工具。仓库自身说明其范围是**知网空间，不是 KNS 全部馆藏**。这一网页请求路径
也不等于知网研学开放平台正式授权的期刊总库 API。可以把它作为**有限的题录发现方式**，先用
MCP `search` 找候选，再核对期刊的期次目录或逐篇页面；不能因为它能返回题录，就推定它涵盖
KNS 全部馆藏、支持无人值守的大量请求或可长期保存所有结果。

2026-09-23 曾以普通、可识别的 HTTP 客户端进行一次小范围公开题名查询：知网空间列表返回
HTTP 200、HTML 和一条与该期刊逐篇页面相符的期刊题录；该列表给出题名、作者、刊名、卷期年份和
记录链接。另一项宽词查询返回 20 条列表项。这只验证了当时的一次**候选发现**，没有证明全库
覆盖、稳定分页、接口许可、期次出版月份或发表时作者机构。**逐篇日级日期不是发现中文期刊
新期次的前提**：这一目的可使用有来源的年、月、卷、期及首次观察时间。万方公开搜索页返回
HTML 页面框架，但这次请求未取得可判读的题录结果；维普所试 URL 返回 HTTP 500。因此两者
的此次结果都是
`unverified`，不能写成“未收录”。具体论文与检索报告仅保留在本地研究记录，不进入仓库。

第三方实现的可借鉴之处是分开返回检索列表和逐篇详情，并区分 `ok`、`blocked`、`error`；
`blocked` 绝不能解释为零篇。其当前列表模型的结构化年份字段只保证年份级线索；部分题录
的期刊文本可能另含卷期，但不能假定所有结果都含出版月份。详情页的 `institution` 解析针对
学位授予单位，不能充当期刊论文作者的发表时署名机构。它限制单页编号，却没有为本项目证明
完整分页或可恢复增量；对 HTML 列表的结构变化也有依赖。它使用浏览器模拟请求；本项目不把
这当作访问授权，也不通过模拟浏览器或挑战页规避来启用正式运行。采用任何代码前还须单独
审查接口、错误脱敏、内容类型、URL 主机、分页和许可，并按其 MIT 许可证保留必要声明。

[知网研学开放平台文档](https://openx.cnki.net/docs/)明确写明 API 目前仅向生态合作伙伴开放；
其[快速入门](https://openx.cnki.net/docs/guide/quick_started_api.html)需要创建应用、申请指定接口
并等待审核。现有公开材料不能证明可获批跨期刊全库题录检索。因此，知网空间 MCP 的公开检索
方法用于**低频、可复核的探索性发现**；正式 API 是另一条待确认的接入路径。本项目适配层重现
该公开检索表单的参数和题录结构，使用普通 HTTP 客户端，不执行第三方 MCP 服务端，也不模拟
浏览器或绕过挑战页。网页的允许用途、长期稳定性及更高请求量的边界仍需继续核查。

OpenAlex 已有的书目核验能力可以帮助识别重复作品、补充日期与机构证据；它也可以作为额外发现
候选的来源，但不替代上述中文数据库覆盖审计。其[主题分类](https://help.openalex.org/data/topics/)
是模型预测，不能直接冒充 PhilPapers 的受控分类。

### 2.3 重点期刊原站目录的月份证据与抽样基线

2026-09-27 对四种哲学相关期刊各抽两篇，以期刊原站目录、知网空间、现有个人订阅的
万方 `OpenPeriodicalChi` 作有界逐篇比对。核对了题名、作者、刊名、年、期；一处
原站主标题与数据库附加副标题不同，保留为题名差异，不自动合并。原站抽样不能用来
估算原站自身的总体召回率；成功的题名查询未命中，也只能称为“本次有界查询未核对到”。
逐篇记录、查询结果和首次观察基线仅保存在 Git 忽略的本地审计文件。

两种可直接访问的独立期刊原站提供了不同的月份证据：[《自然辩证法通讯》2026 年
第 9 期目录](https://jdn.ucas.ac.cn/home/journal/cataloglist/cid/349)对应的
[期刊专栏页](https://jdn.ucas.ac.cn/home/column/lists/cid/349)明确写“2026 年 9 月”，
所以可记 `issue_label_month=2026-09`；[《厦门大学学报（哲学社会科学版）》当期目录](https://xdxbs.xmu.edu.cn/)
明写第 4 期“刊出日期 2026-07-28”，所以可记
`issue_published_at=2026-07-28`，但主页是可变入口，复查时需重新核实期次。
[《哲学研究》期刊门户](https://zxyj.cbpt.cnki.net/portal/journal/portal/client/index)
只显示“2026 年 08 期”，**不据此推断八月**；它由知网承载，也不算独立于知网的
数据库证据。[《伦理学研究》2026 年第 3 期目录](https://llx.hunnu.edu.cn/CN/volumn/volumn_1292.shtml)
在公开搜索索引中显示“刊出日期 2026-05-10”，但本次直接访问返回 502，故该日期
只列为待原站实时复核的证据，不自动补月。该站[年度过刊列表](https://llx.hunnu.edu.cn/CN/article/showTenYearVolumnDetail.do?nian=2026)
与单期页面呈现的期次也不一致，不能仅凭一个列表判定某期不存在。

逐篇题名查询在知网空间找到八篇题录，但全都只有年与期，缺少显式月份；万方查到三篇
完全同题和一篇带副题名差异的候选，其余四篇经完整题名及较短题名的有界查询
仍未核对到。其中两篇来自原站明确标为九月的期次：即使私人检索词另能发现它们，
当前“知网题录缺月则即时拉取不显示”的门槛也无法利用**已有的期刊原站月份证据**。
本次没有测试私人检索词对这些样本的召回，不能将逐篇题名查询说成实际周报命中，
也不能证明论文实际发表于九月某日或万方全库未收录。

万方官方[字段目录](https://github.com/wanfangdata/wfdata-open-skills/blob/master/skills/wfdata-search/references/api-catalog.md)
说明 `MetadataOnlineDate` 是“论文文摘上网日期”。本次四篇已查到的万方题录中，
该字段与原站所标期次刊出日期相差 15 天或 50 天；后者的原站日期尚待直接复核。
这只是两个来源字段的差值，**不是**实际入库延迟。知网空间没有可比的首次收录
时间；真正的来源到达延迟只能从持续复查的首次命中区间估计，不能从一次快照倒推。

因此先建立[重点期刊官方入口目录](../config/official-journals.yaml)与 Git 忽略的
`var/official-journals.sqlite3` 期次证据库，而不对所有站点启用跨站自动抓取。已复核的
明确月份可以为同刊名、同年、同期号且缺月的知网期次题录补月；若两边均有月份而
不一致，则分别保留待核，不无痕覆盖。官方期次即使暂未在知网检出，也可在三种模式的
“官方发布渠道：新期次线索”中单列。期次线索不计入“已匹配新论文”。未接入的维普
不计入上述三入口抽样。

### 2.4 官方期刊监控库与证据录入

当前目录收录《哲学研究》《哲学动态》《世界哲学》《中国哲学史》《现代哲学》
《哲学分析》《伦理学研究》《道德与文明》《自然辩证法通讯》《自然辩证法研究》
《科学技术哲学研究》《周易研究》《孔子研究》《宗教学研究》《中国社会科学》
等 15 种期刊，覆盖综合哲学、中国哲学、外国哲学、伦理学、宗教哲学、科学技术
哲学和一份跨学科综合刊。这是监控范围清单，并非期刊质量排序；其他综合学报中
的哲学论文仍应由全球和中文数据库通道发现。每刊列出可核对的编辑部、
主办单位或期刊门户入口与人工复核状态；主办单位介绍页尚不能当期次目录。

`pfm journal-watch catalog` 查看目录。`pfm journal-watch observe` 把有来源链接的期次
写入私人库；默认 `pending`，只有核过期号、日期字段及官方账号身份的 `reviewed`
记录才会进入检索、即时拉取和周报。字段分别为 `label_month`（期刊明示的年月）、
`issue_published_on`（期刊明示的刊出日）、`announcement_on`（官方公告日）与
`observed_at`（本地首次记录时间）。刊期“月刊”与“第九期”均不能单独证明
“九月刊”。有日期证据的期次可以进入相交的近月窗口；仅有年份或期号不能入窗。
`reviewed_at` 单独记录首次通过人工核实的时间；即时拉取按窗口与日期证据相交筛选，
周报还要求该期首次核实于本周，以免一个九月期在九月每周重复出现。历史检索可查看
所有已复核期次。来源重新读取或重复录入不改变原有首次观察与首次核实时间。
三种模式均须说明当前仅读取本地证据，未实时逐站巡查；本地库没有某期不代表
期刊未出该期。证据库读取错误单列为来源失败，不中断 PhilPapers 主监测。

[《哲学研究》杂志社 2026 年出版期刊介绍](https://zxyj.cbpt.cnki.net/portal/journal/portal/client/paper/fc389b35d2b905d7493c68f9fa1483b5)
写明《哲学研究》为月刊、计划每月 25 日出版，《世界哲学》为双月刊、计划每个单月
2 日出版。这是当年的刊方**出版计划**，可以安排核查周期，不能当作每期已实际在
计划日出版的证明。另有《哲学研究》
[2026 年第 8 期逐篇页面](https://zxyj.cbpt.cnki.net/portal/journal/portal/client/paper/9643564a9e21ad7ae4c3b545272a620e)
明示该篇“发布时间”和“出版时间”均为 2026-08-25；这是逐篇原站时间证据，
也印证不能只看数据库题录中的年、期。《哲学动态》门户本身写明“月刊”，但尚未找到可核实的 2026 年
逐期出版日安排。检索时应回到每一期的目录、封面或公告页面核实。

已收到用户提供的[《哲学动态》2026 年第 9 期公众号链接](https://mp.weixin.qq.com/s/eeYI8s6Y_f9J3zbJ73XgSg)。
本机网页读取与浏览器核验未能取得正文，所以目前只在私人库记录为 `pending`；
不以用户转述的“昨天发布”代替已核实的公众号时间。期刊自身
[门户](https://zxdt.cbpt.cnki.net/portal/journal/portal/client/paper_list/type_benqi)标明“月刊”；
本次七站自动实采时该门户显示 2026 年第 8 期。门户与公众号可能不同步，但因原帖正文
未能读取，目前既不能确认第 9 期的完整目录，也不能以门户第 8 期否定用户线索。
八种原站文字目录与[《现代哲学》中山大学官网目录 PDF](https://mphilosophy.sysu.edu.cn/article/25746)已能有界逐站采集，其余六站仍待逐站处理。新增的[《孔子研究》主办方栏目](https://www.chinakongzi.org/category/kongziyanjiu_qikan/)列出 2026 年第 4 期文字目录；[该期目录页](https://www.chinakongzi.org/content/6147_589032.html)注明 2026-08-13 公告日，但没有明示期次月份，故采集后仍为 `pending`，不能凭“第 4 期”推算月份。《现代哲学》目录 PDF 的“三月号”与官网公告页 2026-06-29 的发布日期分属不同证据链接，不将六月公告日改写为期次月份。自动目录记录进入三种
用户模式前仍须核实期次月份等证据。逐篇兴趣匹配与长期到达延迟测量尚未完成。

## 3. 接入门槛

当前可选的知网空间题录观察只产生**候选**与**期次线索**，不作为已核验的新论文通知。若要把
任一中文来源升级为完整的自动发现、逐篇核验与匹配来源，应取得并验证：

1. 来源允许的访问方式与使用范围，含请求频率、缓存和结果展示条件；凭据只放在本地私密环境；
2. 稳定记录 ID 或 DOI、题名、作者、期刊、作品类型、来源链接，以及必要时的发表时作者机构；
3. 明确区分首次在线发表、卷期标示月份、实际可确认的卷期上线时间、数据库收录、索引更新及
   网页更新；保留年／月／日原有精度，不要求每篇期刊论文都有日级日期；
4. 对声称完整的检索范围验证分页或增量机制、错误页识别、限速处理和中断恢复；若探索性 MCP
   检索仅完成有限页，报告明示页数及“覆盖未证实”，不将它解释为查无论文；
5. 对进入“已匹配论文”主栏的记录，采用经审核的来源分类映射或经用户确认的独立中文兴趣分类；
   关键词命中、期刊名称或模型生成标签不能静默满足 PhilPapers 分类交集。仅作为“新期次观察”
   的条目可注明检索词与刊名，并明确其文章尚未通过逐篇兴趣核验；
6. 最小、无凭据、可再分发的测试夹具，以及对缺字段、重复、旧文补录、网络首发和来源失败的
   回归测试。

这些门槛沿用[监测政策](monitoring-policy.md)、[兴趣标签规则](interest-tag-matching.md)、
[日期与版本语义](date-and-version-semantics.md)、[安全与隐私政策](security-and-privacy.md)和
[来源重试政策](source-retry-policy.md)。来源返回 HTTP 200 不等于字段语义或覆盖范围已获证明。

## 4. 三种模式的共同与不同处理

### 4.1 共同的候选与证据层

三个模式共用同一套来源无关的作品模型，但保留逐来源原始事实，不在输入时把不同日期或字段
压成一个值。每条候选至少保存：来源、来源记录 ID、规范链接、检索时刻、题名、作者及顺序、
期刊与卷期、明确的卷期标示月份、作品类型、DOI、来源自称的日期及日期类型、作者署名机构及其
证据位置、来源分类、检索状态与内容契约版本。缺失字段记为 `unknown`；不得由姓名、中文题目、
期刊国别或作者现职推断发表时署名机构。

候选发现、书目事实核验、兴趣匹配、新近性核验是四个独立判断：

1. PhilPapers 继续按已确认分类发现全球候选，不施加中国机构过滤。
2. 获准启用的中文来源按经用户确认的中文术语或来源受控类目发现补充候选；英文分类的机器
   翻译仅能提出检索式和映射建议，不能自动成为已确认的 PhilPapers 分类 ID。知网空间结果可在
   有限人工试验中提出候选，但关键词命中本身不构成兴趣分类证据。
3. 同一作品先以 DOI、稳定来源标识符或明确共享标识符合并；题名、作者、年份与期刊用于生成
   待复核匹配，不能仅凭题目相似自动合并。不同来源链接和有冲突的字段全部保留。
4. 发表时机构优先从论文原文署名页、期刊或出版方的逐篇页面取得；其他数据库的明确逐篇作者
   机构字段可佐证。学位授予单位、作者主页现职和数据库归属不替代该证据。
5. 在线首发、卷期出版、数据库首次出现、检索时刻分别建字段。旧作后来进入知网空间或万方／
   维普时只能形成来源到达事件，不能直接成为本周新论文。

### 4.2 交叉验证的用途与分歧处理

对需要交叉核对的中文来源候选，以**规范题名、作者、年份、期刊及 DOI／来源 ID**为组合查询键，优先核对期刊或出版方页面，按可用权限选择知网、万方、维普或国家哲学社会科学文献中心。万方默认不开启，其有界未命中不得成为排除刊方论文的理由。万方 AI HUB 的已订阅
[Query 接口](https://ai.wfdata.com/skills/api)可在本机配置密钥后用于有限交叉核对；
另一个[万方选题接口示例](https://topic.wanfangdata.com.cn/api.html)使用不同的签名方式，不能
直接等同于这个接口。维普的[期刊平台](https://jxzgb.cqvip.com/)
可供人工核对。各来源的实际可用接口及使用许可须分别核实。

交叉核对返回四类状态：`corroborated`（独立记录支持同一作品与具体字段）、`conflict`
（明确事实冲突）、`not_found_in_completed_scope`（在**成功且范围明确**的查询中未找到）和
`unverified`（未查、受阻、错误、页数不全或来源范围不明）。后一类绝不转换为“不存在”。
另一数据库没有该文，不自动否定知网候选；多库同录，也不自动证明某一发表日期正确。出现日期、
作者或作品类型冲突时展示原始证据并暂缓自动新论文通知；期刊逐篇页面或论文首页可解决具体
字段冲突，但不能证明其他数据库已完整收录。

试运行以少量预先选定的哲学期刊论文分别观察有 DOI／无 DOI、有线上首发／只有卷期日期、
已在 PhilPapers／未在 PhilPapers 的情形。逐项记录来源是否成功、检索范围、页数、字段一致性、
署名机构证据、日期精度和首次观察时间；每种数据库需重复跨日核对才可估计到达延迟。公开仓库
只保存聚合验证结论和可再分发的最小合成夹具，不保存原始检索报告或私人研究方向。

### 4.3 月份精度与新期次观察

中文期刊的卷期常以“年＋期号”呈现，部分期刊另有明确月份。**第 9 期不必然等于 9 月刊**：
只有来源确实标为“2026 年 9 月”，或者期刊可靠说明其月刊期号与月份一一对应时，才写
“2026 年 9 月刊”。其他情形写“2026 年第 9 期”，月份记为未知。即使有月份，这通常也是
**卷期标示月份**，并非逐篇首次公开日，也不一定等于网页实际开放月份。

周报为此采用一个与“确认本周发表论文”分开的**中文期刊新期次观察**口径：

1. 使用经确认的中文检索词，按 MCP `search` 的期刊检索方法请求知网空间公开题录（相当于
   `kind=journal`，周报限定相关年份）；保留查询、页码、状态和检索时刻；受阻、错误、不完整
   翻页均列为覆盖不明。私人检索词只保留在 Git 忽略的 watchlist，不进入公开状态或文档。
2. 当前以规范刊名、年份和期号构成期次键；知网空间列表页显示的期次是题录线索，不证明
   整期刚发行。系统保存首次观察时间及题录链接，后续周报不重复把同一期当作新发现。升级为
   经期刊确认的期次前，还要核对期刊原站目录；有卷号或稳定期刊标识时再加强期次键。
3. 在首次观察落入本周且期次与当前月份相关时，周报可写“本周首次发现《某刊》2026 年
   9 月刊／第 9 期”，列出相关候选文章及核验状态；若期次月份早于当前月，则写“较早期次
   本周才发现”，不能倒填为当时已监测到。只有年份和期号时按期号写，不推算月份。
4. 逐篇文章如有在线首发的日级证据，另按日判断首次公开；没有日级日期的，不因此从期次
   观察栏消失，也不声称它在本周首次发表。文章进入“已匹配论文”主栏仍须完成作品类型、
   机构范围、身份去重和兴趣匹配核验。

例如 9 月某周发现期刊网站已有明确标为“2026 年 9 月”的新一期，周报可报告**9 月期次
本周首次见到**，并写明所见时间及相关论文。这个陈述不需要替每篇论文补造 9 月某日的发表
日期，也不等于宣称整期在本周出版。若期刊先在 8 月上线标为“9 月刊”，应保留实际首次观察
在 8 月的事实，不能等到 9 月再写“9 月新发现”。

### 4.4 各模式的处理

- **独立检索**：当前使用与 MCP 相同的检索方法发现中文期刊候选，单列于已核验 PhilPapers
  结果之后，不施加“本周新出”门槛。只有年月或期号的题录仍可检索，不因缺日级日期被排除；
  但尚未完成中文候选的兴趣映射、机构与跨来源去重，不能把候选计入已确认的并集。受阻或
  未完成的页数明确披露。
  可选万方独立发现另列候选，且不以知网命中为前提；来源年、月仍按原始字段标示。
- **即时拉取**：中文栏只列来源**明确标示卷期月份**、且该月份与用户选择的滚动窗口相交的
  期刊论文线索；仅有年份或期号的题录，以及月份在窗口外的题录，不列出题名。覆盖栏分别记录
  扫描到的总期次数、缺少月份与窗外期次数；万方逐篇核对也只针对本次可列出的线索。
  月份相交只说明卷期标示月份可能覆盖窗口的一部分，不证明文章在窗口内某日首次发表；
  因缺月而没有可列线索时，不得断言近月没有中文论文。用户可另行要求扩大时间范围或独立检索。
  已确认新论文主栏沿用周报的作品类型、兴趣与旧作核验标准，不写入正式周报通知历史。
  可选万方独立发现使用单独栏目，只列万方自称出版月份与窗口相交的候选；`1 月 1 日`
  这类可能由年份补齐的占位日期不算月份证据。万方月份不替代知网卷期月份。
- **周报**：在持久基线之后增量发现。新增来源失败时不得把它解释为零篇，也不得把它的上次
  成功检查点推进至本周。用独立观察栏报告本周首次发现的期次线索；旧论文在中文库补录只可
  标为旧作补录，不成为“本周新论文”。
  万方独立发现另按逐篇记录 ID 建窗口内有界基线；同一期后来新增 ID 可成为新观察线索，
  仍不得称作本周首次发表。万方已见 ID 与正式周报同事务提交。

后续跨来源去重应先使用 DOI 和可核验的共享标识符，再用题名、作者、年份及来源证据比较。
中英文题名可能互为译名；没有共享标识符时不能仅凭语义相近自动合并。届时报告需保留各来源
原始链接、各自日期和冲突说明。

## 5. 当前结论

当前 `pfm` 可在私人 watchlist 中启用 `sources.cnki_space`，设置经用户认可的中文题名／主题词与
每项检索最多页数。三种模式均使用受限的知网空间题录发现：`search` 单列中文候选，不计入
PhilPapers 已核验结果；`pull-now` 只读展示有月份证据且月份与窗口相交的期次；`weekly-run` 将第一次扫描作为
基线，以后仅单列此前未见的期次，并在同一事务中保存期次与周报状态。周报显示原始期号与首次
观察时间，不把“第 9 期”写成“9 月刊”，也不把列表中的日级时间当作首次发表日期。失败和页数
截断计入来源覆盖，不能解释为零篇。

第二步增加了**私人、人工核对的逐篇证据文件**：在私人 watchlist 的 `sources.cnki_space` 下设置
`reviewed_evidence: "var/cnki-reviewed-evidence.yaml"`，文件使用 `version: 1` 与 `records` 列表。
每项给出知网题录 URL、不同于知网空间题录的期刊或目录页面 URL、`source_type`（`journal_article`、
`journal_issue` 或 `catalog_record`）、来源所载题名、作者列表、刊名、年份、期号和有时区的
`reviewed_at`。只有逐篇期刊页面确实标出作者在中国机构的署名，才可填写
`china_affiliated_authors`。程序以题名、作者顺序、刊名、年份、期号及原知网 URL 逐项比较：
完整相符才标为书目已核对，冲突列为需复核；缺少年份或期号只算部分核对。核对文件位于 Git 忽略
目录，不写入公开示例或日志。程序不会自动访问这些来源页面，也不会仅凭人工条目认定论文在本周
首次发表、进入已确认兴趣分类或将它加入已核验论文总数。

本次检索已解析到的 PhilPapers 书目会与中文候选做严格题名比较；题名、首作者和年份都一致时
显示书目重合线索，其余同题结果提示身份待复核。这个比较只针对本次实际读取并解析的记录，
跨语言译名可能无法识别；即使字段一致，也保留两边来源链接且不自动合并。国家哲学社会科学
文献中心的[用户协议](https://m.ncpssd.org/docs/UserAgreement.html)限制未经许可的非人工抓取；
万方 AI HUB Query 已有可选适配层：私人 watchlist 可设置 `sources.wanfang.enabled: true` 与
`max_checks: 5`，同时在本机进程环境设置 `WFDATA_APP_KEY`，或配置指向 Git 忽略目录的
`key_file: "var/secrets/wanfang-app-key.txt"`。密钥文件只包含 AppKey 一行。它仅查询最多五条知网候选的
`OpenPeriodicalChi` 题录，最多两页，逐项比较题名、作者、刊名、年份及期次。缺少密钥、认证
失败、结构异常或截断会标出覆盖限制，未核对到同题记录不等于未收录。本机试用订阅的有限
真实调用已确认返回的 `numFound` 可以是数字字符串，题录在 `Periodical` 对象中，
`PublishYear` 可为 0；实现及合成夹具现覆盖这些形式，并从非空 `PublishDate` 提取年份。
私人检索结果不进入公开文件。期刊逐篇发布门户
若由知网承载，它可以补充刊物的书目与署名信息，但不算万方或维普的独立收录确认。

若另设 `sources.wanfang.discover: true`，万方 Query 还会独立发现有限中文期刊候选，
无须先有知网命中；检索、即时拉取和周报分别按上文的候选、月份窗口和逐篇 ID 基线口径
显示。该开关默认关闭，以免未确认额度时增加请求。开启后仍只使用既有个人订阅可返回的
范围，不宣称拥有全库权限；来源返回的日期和机构字段也不自动满足发表时间、作者身份或兴趣
匹配门槛。维普的自动接口仍未接入。

中文候选仍未进入已核验论文主栏；人工核对目前只覆盖私人证据文件中有来源支持的条目，其他作者
机构、PhilPapers 作品同一性及万方／维普逐篇收录仍未全面核实。知网空间并非完整 KNS，有限页
扫描也不保证覆盖全部中文论文。正式授权接口的申请仍是一条并行路径。**日级发表日期不是期次
观察的接入条件**，但缺少日期不能使候选自动变为已确认新论文。
